# Cryptography, secure systems, and low-level computing

I'm Amrish Hallberg. I write about building secure systems, understanding the mathematics beneath them, and testing what actually happens on real hardware.

This is an experimental, static-first version of the site: HTML for reading, and small WebAssembly modules for computations that benefit from them.
